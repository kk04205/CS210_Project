## Group Members

## Project Overview
This project focuses on diabetes risk classification using BRFSS-derived health indicators.
We integrate relational database design, ETL, exploratory data analysis, and machine learning.

## Project Structure
- `sql/` : database schema and analysis queries
- `src/` : ETL and modeling scripts
- `data/` : raw and processed datasets
- `outputs/` : figures and model results

- PostgreSQL
- Python
- pandas
- scikit-learn
